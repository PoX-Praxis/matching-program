# 「応える」の原則 v1

**作成:** Claude（KAORU の決定 2026-11-18・Sakana の助言 2026-11-18 四回目）
**位置づけ:** 生成仕様 v1.0（案2）§5 の照合と、§5-3 の表のよりどころ。物差し（60 組の付け直し・v2・48 組の正解）も、この原則で付ける
**ゴール:** G2・G3　**層:** 3（要素）・4（表示）　**根幹か枝か:** 枝（根幹 §4-2「言い切れないなら言い切らない」を、要素の単位で文にしたもの）
**例は、すべて架空の 60 組（`synthetic_v1`）から取った**

---

## 0. 一つの原則

> **要素の単位では、型・述語・対象・条件が合うものだけを「応える」とする。**
> **目的の単位で役に立つものは、別の名前で正直に出す。いまの R1〜R4 を言い換えて「応える」とは言わない。**

v1.0 では、目的の単位の別の名前（下の §5）は**まだ出さない**。出さないことは「意味がない」という判断ではなく、v1.0 の範囲の決定である。

## 1. 必要の型（必要の文から機械が決める）

| 必要の文 | 型 |
|---|---|
| 〜してきた人・〜を担ってきた人 | 役割（経験を求める） |
| 〜できる人・〜の立場で関われる人 | 役割（申告でよい） |
| 〜を**持つ**人で、対象が**技術・能力・経験・知識** | 役割（能力）。「持つ」だけで資源にしない（S43） |
| 〜を持っている人・〜を貸し出せる人で、対象が**物・場所・資金・機材** | 資源 |
| 〜を持っている人で、対象が**資格** | 資格。役割の代わりにはしない |
| 〜に関心がある人 | 関心 |
| （相手の文）場所・物を使わせる権限がある（管理を任されていて、利用の受付ができる など） | 資源の提供とみる（S17。KAORU 2026-11-18） |
| （相手の文）〜が好き・〜が趣味 | その行いを好むこと。関心の必要への「関心がある」とはしない（S28・S35） |
| 名詞だけ・述語が複数で中心が決まらない | 型なし（照合しない） |

## 2. 型の互換（要素の単位）

| 必要の型 | 応える句の種類 | 関係 | 応えないもの |
|---|---|---|---|
| 役割（経験を求める） | 経験 | R1 | 資源（P1）・関心（P4）・一部の手伝い（P3） |
| 役割（経験を求める） | 必要と**同じ種類の役割**の申告 | R2 | 同上 |
| 役割（申告でよい） | 経験・同じ種類の役割の申告 | R1・R2 | 同上 |
| 役割（能力） | その能力の経験・申告 | R1・R2 | 機材などの資源（S43） |
| 資源 | 資源（同じ種類の物・場所・資金） | R3 | 経験・申告・関心 |
| 関心 | 関心（同じ領域） | R4 | 経験・行い（P2）・消費（S23 型） |

- 互換の後に、述語・対象・条件が合うかを見る（生成仕様 §5-2・§5-3）。判定は 3 値（合う／合わない／分からない）。分からないは落とす
- 関門（主語が相手でない・否定・推量・伝聞・希望・受身・受益・探索・募集）に当たる句は、型の前に落とす

## 3. 四つの判断（P1〜P4）

| | 問い | 決定 | 架空の組 |
|---|---|---|---|
| P1 | 資源で、役割の要素に応えるか | **応えない。**ただし、その目的に資源の要素が別にあれば、そちらに R3 で応えうる。要素ごとに見る | S08・S43・S55 は、役割の要素には応えない |
| P2 | 経験・行いで、関心の要素に応えるか | **応えない。**相手は関心を書いていない。「同じ関心がある」とは言わない | S27・S32・S47・S57 |
| P3 | 一部の手伝いの申告で、役割の要素に応えるか | **必要と同じ種類の役割の申告だけが応える（R2）。**一部の手伝い・隣の役割は応えない | S52 は応える。S12・S02・S22・S37・S07 は応えない。S42（必要「音響や照明など、裏方の技術を持つ人」・相手「照明の操作を担当できる」）は、照明が必要の例に入っているので、同じ種類の役割として応えるとみる（付け直しで確かめる） |
| P4 | 関心の文で、役割の要素に応えるか | **応えない。**「同じ関心（R4）」は、N の**関心の要素**にだけ付ける。補完の目的で R4 だけなら、いまの規則どおり出さない | S13・S38 は、役割の要素には応えない |

## 4. 言い切らないこと

- R2 の［C］「その立場で関われる、と申告しています」は、必要と同じ種類の役割のときだけ使う。一部の手伝いに使わない（S12 の言い過ぎを繰り返さない）
- R4 の［C］「同じ関心がある、と書いています」は、相手が関心を書いているときだけ使う

## 5. 次に足す候補（v1.0 では出さない）

| 名前（仮） | 中身 | ［C］（仮） | 足すのに要るもの |
|---|---|---|---|
| 部分 | 必要の役割の、正しい一部・工程を手伝える（S22・S37・S07） | その役割の一部（〜）を手伝える、と申告しています | 役割を工程に分けた小さな表（運営／直接支援／制作の工程／申請／営業・紹介 など）。S22・S37・S07 が入り、S12・S02 が入らない粒度 |
| 同じ領域の行い | 関心の要素に対して、同じ領域の行いを書いている（S27・S32・S47・S57） | N が関心を持つ「…」について、O は「…」と書いています（行い） | 述語・対象が同じ領域かを見る表。S23 型（消費）を落とす |

- 足すかどうかは、v1.0 の測定で、説明が出る割合を見てから決める
- 足すときも、R1〜R4 の文を言い換えて使わない。別の名前・別の［C］にする

## 6. 物差しへの当て方

- **60 組の付け直し（ラベル r2）**
  - 元の正解（r1・2026-11-12）は消さずに残す。r2 は別のファイルにする
  - 組ごとに、変えた理由を P1〜P4 のどれで書く
  - 「原則を決めた上での適用の修正」であり、モデルの結果に合わせた変更ではないと記録する。ただし、モデルの出力を見た後に付けたことも記録する
  - 付け方：Claude が原則から案を作る。別の会話にも、原則と 60 組だけを渡して付けさせる（モデルの出力は渡さない）。食い違った組は、KAORU が決める
  - 60 組は開発用のまま。最終の判定には使わない
- **v2・48 組**：この原則で正解を付ける。モデルを走らせる前に固定する。走らせた後に変えたら、新しい版として扱う
- **説明が出る割合**の分母は、この原則で「説明できる」とした数。古い 24 は使わない。目的の種類（補完・共鳴）と関係ごとに分けて数える
