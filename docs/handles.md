# ハンドル（指示書55・55-2 PR-D）

表示は **「表示名（@ハンドル）」**。同一性の根拠は subject_id（画面には出さない）。

| 層 | 性質 | 変更 |
|---|---|---|
| 表示名 | 見せる名前。重複可 | 本人がいつでも変えられる（版を作らない） |
| ハンドル | **一意・不変**の短い識別子（`@kaoru`） | 本人は変えられない（例外は下の規則） |
| subject_id | 内部のみ | — |

## 規則

- 書式: 英小文字・数字・`_` の 3〜30 字（大文字は小文字にそろえる。`@` は付けずに保存）。
  予約語（`admin`・`api`・`u` など）と、**他の人の subject_id と同じ文字列**は使えない。
- **登録時に確定（必須）**。確定の画面で「後から変えられません」を先に見せる。初期値は①の出力の
  `"id"`（英数字のハンドルネーム）。
- **既存ユーザー**は設定するまで表示名のみ。マイページに「ハンドル」の入力欄（導線）を出す。
  1 度確定したら欄は消える。
- **プロフィールの URL は `/u/<ハンドル>`**。旧 URL `/profile/<id>` はハンドルがあれば 301 で移す
  （アドレス欄に生 id を出さない）。ハンドル未設定の人は旧 URL のまま。

## 例外の変更（運用）

- **本人の申立て**があったときだけ、運用者が `scripts/change_handle.py` で行う（公開の API は無い）。
- **一意性を保つ／1 回だけ／旧ハンドルは退役させて再利用しない**（過去の引用・URL の行き先が別人に
  ならないように）。旧ハンドルの URL は 404 になる。
- 変更は通常DB `handle_changes` に記録する（画面には出さない。台帳には書かない）。
