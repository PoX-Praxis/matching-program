## 5. 決まっている大事なこと（要約）

- 照合は nomic（C2+b-1・δ −0.020・10件ずつ・並びは中立）。上層の印は保留（関係のある組だけ）。下層は一覧で開かない。66C は退役
- 説明：生成してよいのは ① だけ（根幹 §4-3）。②③は原文の抜き出し、④は R1〜R4、⑤は決まった型。確かめを通らないものは出さない。説明は「選ばれた理由」ではなく「つながる意味の解釈」。並び順は近さの順ではない
- 外部の AI を使わない（判定・計測・本番の生成）。推論は KAORU の PC
- 数値を画面と公開 API に出さない
- 基準テストは全員の説明の質を決めるモデル選定の合否にだけ使い、プロンプトの調整には使わない
