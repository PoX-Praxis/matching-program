## 3. 機械の［A］（順1 で作る）

入力は照合の表が出した `offer_quote`。出力は「〜人です」につながる［A］。**規則に当たらないとき・迷うときは、［A］を作らず型の ① にする**（崩れた日本語より型の ① の方が誠実。Sakana）。

| # | 規則 |
|---|---|
| 1 | 末尾の「。」と、節をつなぐ助詞（〜が・〜ので・〜けれど など）を除く（表の W9 と同じ） |
| 2 | 末尾の丁寧の形を常体にする。**許すのは次だけ：**「〜てきました／〜ていました」→「〜てきた／〜ていた」・「〜しました」（サ変）→「〜した」・「〜できます」→「〜できる」・「〜ています」→「〜ている」・「〜あります」→「〜ある」・一段動詞の「〜ました」→「〜た」・「〜ます」（一段・サ変・可能動詞）→ 辞書形。**五段動詞の「〜ました」（音便が要る：書きました→書いた）は型の ① にする** |
| 3 | 末尾が、動詞・「できる」・「ある」・「いる」・助動詞「た」で終わること（「〜人です」に係れる形）。名詞・「です」・「だ」で終わるときは型の ① |
| 4 | 否定・推量・希望の形が残っていないこと（表の関門を通っているので無いはず。あれば型の ① とし、記録する） |
| 5 | ［A］は 40 字以内。超えれば型の ① |
| 6 | 内容語は offer_quote のまま（足さない・消さない・言い換えない）。条件（頻度・期間・曜日・「〜なら」）を保つ |

- できあがる ①：「{O}は、［A］人です。{N}が求める「［B］」には、［C］。」（［B］［C］は表が出したもの）
- 型の ①：「{N}が求める「［B］」について、{O}は「［offer_quote］」と書いています（［短い名前］）。」
- **単体の試験：**examples_v1 の肯定 7 組で、機械の［A］が、お手本の［A］（`stage2.A`）と一字も違わないこと。違えば止めて報告する（規則を Code が足さない）

## 4. 順1：表＋機械の［A］を v2 で測る（GPU なし・費用 0）
