# 指示書（docs/instructions/）

指示書を 1 ファイルずつ置く。決まりは `docs/OPERATIONS.md` §2、テンプレートは `_template.md`。

## 置き方

- **ファイル名:** `<番号>.md`
  - 番号は指示書の番号をそのまま使う（例: `66.md`・`65B-7.md`・`66C.md`）
  - 追補は `<番号>-addendum<n>.md`（例: `66C-addendum2.md`）
  - 番号の無い指示書は、短い英小文字の識別子にする（例: `repo-operations.md`）
- **入れる時:** その指示書の PR の、最初のコミット
- **本文:** 受け取ったまま入れる。伏せた部分があれば、冒頭に「何を伏せたか」を書く

## 過去の指示書（06〜66）は、後から入れる

過去の指示書の本文はリポジトリの外（チャット・アップロード・Notion）にある。いまはここに無い。

- 入れるときは、まとまりごとに 1 コミットにする（例: 「指示書 55〜58 を後から入れる」）
- 各ファイルの冒頭に、次の 3 つを書く
  - **後から入れた**ことと、入れた日
  - **元の日付**（受け取った日。わからなければ、対応する PR のマージ日）
  - **対応する PR の番号**
- どの番号が入っていて、どれがまだ無いかは、入れたときにこのファイルの末尾の一覧に足す

## 入れるときの除外の決まり

`docs/OPERATIONS.md` §5 に当たるものは伏せる。指示書で特に気をつけるのは次のもの。

| 伏せるもの | 例 | 置き換え方 |
|---|---|---|
| 個人の文 | KAORU・PA の必要像・与え像・現状の文、抜き取りで見せた文 | 「（KAORU の必要像 1-1。本文は `local/`）」のように、識別子だけにする |
| 生テキスト・根拠の本文・`evidence_span` | 登録の素材の引用 | 「（根拠の本文・伏せた）」 |
| 本人以外の数値 | PA の gate など | 「（PA の数値・伏せた）」 |
| 計測の個別の数値 | 対ごと・人ごとのスコア、抜き取りの票の中身 | 集計と判定だけを残す。集計は `docs/measure/` の文書を指す |
| 秘密 | トークン・メールアドレス・URL に入った鍵 | 「（秘密・伏せた）」 |

- 伏せたら、冒頭の「伏せた部分」の欄にまとめて書く
- 判断に迷うものは入れずに、報告の「判断が必要な点」に挙げる
