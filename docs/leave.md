# 離脱（指示書51・発注者の決定 2026-09-28）

## 範囲
- **コミュニティからの離脱**: 既存の `member.left`（41 §4）。`POST /api/community/<id>/leave`（本人のみ）。コミュニティ画面に導線。
- **プロジェクトからの離脱**: 新設の `intent.participant.left`（台帳の新設はこの 1 型のみ）。`POST /api/projects/<intent_id>/leave`（本人のみ）。プロジェクト詳細の発言欄の近くに導線。
- **作らない**: 除名（他人を離脱させる経路）・権利の剥奪／凍結・離脱の理由の記録・コミュニティとしての参加の離脱（未決・51 (b)）。

## 型
```
intent.participant.left { intent_id, participant, participant_kind, joined_ref, recorded_at }
```
- `joined_ref`: 対応する `intent.participant.joined`、代表の場合は `intent.launched` の event_hash。
- 理由・経緯は入れない。`recorded_at` は判定に使わない。

## 分母
`governance.participants_at(intent_id, basis_seq)` は seq の順に「立ち上げで加え・参加で加え・離脱で外す」。**seq ≤ 基準点の事実だけ**を見るので、基準点より後の離脱は過去の合意の分母に遡及しない。離脱後に改めて参加が承認されれば再び加わる。

## 離脱できない場合（409）
| 対象 | 条件 | 理由 |
|---|---|---|
| プロジェクト | 既に離脱済み（二重離脱） | — |
| プロジェクト | 完了済み | 離脱は実行中のみ（51 §5-6） |
| プロジェクト | **最後の 1 人**（代表かどうかに依らない） | 分母が 0 になると、取消も撤回も無い以上、復旧手段が無い（51 (a)） |
| コミュニティ | メンバーでない／既に離脱済み | 二重離脱（以前は 200 を返していた） |
| コミュニティ | **最後の 1 人** | 同上（プロジェクトと同じ規則を当てた。推測で補完） |
| コミュニティ | **創設者で、初回の `intent.completed` の前**（ブートストラップ期） | 51 (c) |

## 創設者（51 (c)）
- **権限**（議決・操作・編集・承認）: 在籍している間だけ（`community.has_founder_rights` = 創設者 かつ 台帳で離脱していない）。
- **事実の表示**（「作成者: …」）: 離脱しても残す（`communities.founder` は変えない）。

## 権利
離脱しても、実績・持ち分・将来の発行を受ける権利は本人に帰属したまま（41 §7-1）。完了の記録・参加の記録・軌跡の枝は消えない。画面に「離脱しても、実績と持ち分は残ります」と出す。
