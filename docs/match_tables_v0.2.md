## 0. v0.1 からの変更

| 変更 | 理由 |
|---|---|
| 言い換えの対ではなく、**領域の概念表**（§5）で対象の領域を見る | 言葉が重ならない正しい組（S16・S26・S31・S46）を、概念で拾う（Sakana） |
| nomic は対象の句どうしだけ。名詞の種類か概念の一致を条件にした補助（§6） | nomic 単独で「合う」としない |
| 対象の下位の種類を足す（§4） | 軽い動詞（担当する・担う）を対象から決めるため |
| 主な動詞は「誰に・何を」の枠で見る（§3-2） | 「数学を教える」と「機器の使い方を教える」を分けるため |
| 資源を**所有**と**使える立場**に分ける（§2） | S17 を「持っている」と言うと言い過ぎ（KAORU・Sakana） |
| **継続**（現在＋期間）と**現職**（仕事にしている）を、経験から分ける（§2） | いまのことを過去のように言わない（KAORU・Sakana） |
| 必要の文に条件があれば、相手の条件と比べる（§7） | 条件を判定に使わないのは言い過ぎ（Sakana） |
| 関門の範囲を書く（§1） | 消費・学ぶ側の関門は、役割と資源の必要に効く。関心の必要は、v1.0 では「関心がある」の明示が要るので、結果は同じ |

## 1. 関門（抜き出した句の中心の述語で見る。当たれば落とす）

| 関門 | 形 | 60 組の例 | 効く必要の型 |
|---|---|---|---|
| 主語が O でない | 三人称（知人に〜がいる・兄が〜）・一般論（〜する人は多い） | （最小対で足す） | すべて |
| 否定 | 動詞＋ない・〜したことがない・〜できない | （最小対） | すべて |
| 推量・伝聞 | 〜かもしれない・〜だろう・〜らしい・〜そうだ・〜と聞いている（文の終わり） | （最小対） | すべて |
| 希望 | 〜たい（＋と思っている／と考えている）・いつか〜・将来は〜 | S05・S20・S54 | すべて |
| 気持ち・後悔・評価 | 文の中心が「思っている」で、「関心」を含まない（〜ばよかったと思っている・〜を自慢に思っている） | S40・S58 | すべて |
| 受身・受益 | 中心の動詞＋れる／られる（行う人が O でない）・〜てもらう・〜ていただく | S49 | すべて |
| 探す・募集する | 〜を探している・〜を募集している | S03・S23 | すべて |
| 消費 | 動詞と対象の組（§3-1）：映像・動画を見る・聴く・食べる・食べ歩く・ライブに行く・小説を読む・機能を調べる | S03・S23・S33・S44・S53 | 役割・資源 |
| 学ぶ側 | 習う・習い始める・教わる・学ぶ | S25・S50 | 役割・資源 |

- 「気になっていて、…関心がある」（S26）は、中心が「関心がある」なので落とさない
- 「管理を任されていて、利用の受付ができる」（S17）は、中心の述語（受付ができる）で見る。「任されて」は O が行う立場を表すので、受身の関門には当てない
- 「祖父母から聞いた…話を」（S31）の「聞いた」は、文の終わりではないので伝聞ではない

## 2. 句の種類

| 種類 | 形 | 関係 | ［C］（① の生成） | 型の ① の短い名前 |
|---|---|---|---|---|
| 経験 | 〜てきた・〜てきました・〜た・〜ました・〜を続けてきた | R1 | その役割を担ってきた、と書いています | 経験 |
| 継続 | 現在の形（〜している）＋期間（十年・八年間 など） | R1 | その役割を〔期間〕続けている、と書いています | 継続 |
| 現職 | 〜を仕事にしている | R1 | その役割を仕事にしている、と書いています | 現職 |
| 申告 | 〜できる・可能の形（手伝える・関われる・担当できる）・〜ことができる・〜の立場で関われる | R2 | その立場で関われる、と申告しています | 申告 |
| 資源（所有） | 〜を持っている／持っていて・〜を貸し出せる・〜を提供できる（対象が物・場所・資金・機材。自分のもの） | R3 | その資源を持っている、と書いています | 資源 |
| 資源（使える立場） | 場所・物を使わせる権限（管理を任されていて、受付ができる など。自分のものではない） | R3 | その場所を使える立場にある、と申告しています | 使える立場 |
| 関心 | 〜に関心がある・〜に関心があり | R4 | 同じ関心がある、と書いています（補完ではありません） | 同じ関心 |
| v1.0 では応えない | 〜が好き・〜が趣味（好み）・〜が得意（自己評価）・〜に詳しい（知識）・現在の形で期間なし（〜している） | — | — | — |

- 〔期間〕は、相手の句にある期間の語を機械が入れる
- 記録（pair_digest）の関係は R1〜R4 のまま。下の種類（継続・現職・所有・使える立場）は、関係の規則の版（rel-v0.5 の案）に入れ、① の言い方を決めるのに使う
- 「v1.0 では応えない」は、落として開発用のログに残す（v2 の候補：§9）

## 5. 領域の概念表（v0.1。60 組から）

対象の領域が合うかは、まず概念で見る。必要の句と相手の句が、同じ概念に入れば「合う」。

| 概念 | 必要の側に要る語（どれか） | まとめる句 |
|---|---|---|
| food.processing | 食品・加工 | 食品の加工・衛生管理・工程・仕込み・殺菌・衛生記録・ジャム工房・加工品 |
| sales.channel | 販路 | 販路・通販・ネット通販・小売店・百貨店・催事・出店・物産・道の駅・直売所・卸す |
| youth.place | 子ども・学習支援 | 子どもの居場所・学習支援・学習教室・放課後・学校に行けない子 |
| place.community | 空き部屋・集会所 | 空き部屋・集会所・離れ・稽古場・公民館・場所として |
| craft.record | 職人の作業 | 職人の作業・研削作業・映像・手順書・動画・教材・撮影・記録 |
| craft.inheritance | ものづくり・職人・工芸 | ものづくりの技術・技・受け継ぐ・継承・後継者・伝統工芸・弟子を育てる |
| local.history | 地域・町・昔の暮らし | 地域の歴史・昔の暮らし・戦前の町の話・祖父母から聞いた・郷土史 |
| elder.listening | 高齢の方＋聞き取り | 高齢の方・話を聞き取る・思い出話・利用者・冊子・文章にまとめる |
| event.backstage | 音響・照明・裏方 | 音響・照明・裏方・ライブハウス・会場 |
| young.artists.support | 表現者・画家・音楽家・演劇 | 若い表現者・若手の画家・音楽家・演劇グループ・活動を続ける・暮らしていける |
| elder.devices | 高齢の方＋機器・操作 | 高齢の方・機器の使い方・携帯電話・スマートフォン・操作 |
| isolation.prevention | 孤立 | 孤立・見守り・一人暮らし・地域の仕組み |

- **「必要の側に要る語」**は、その概念の中心の語。相手の句に、まとめる句が出ても、必要の句がこの語を持たない概念には入れない（「IT 技術が受け継がれる」は、ものづくり・職人・工芸の語が無いので craft.inheritance に入らない）
- 1 つの句が 2 つ以上の概念に入るときは、必要の句と同じ概念があれば、それを使う
- 概念を足すときは、2〜3 例か原理の理由が要る。60 組の 1 組だけのために足さない。v2・48 組は見ない
- LLM に概念を選ばせる場合は、この表の閉じたラベルから 1 つを提案させるだけ。採否は機械

## 6. 対象の領域が合うかの手順

1. 概念表（§5）で、必要の句と相手の句が同じ概念に入る → **合う**
2. 入らない → 対象の句どうしだけを nomic で比べる。次の **両方** を満たすときだけ **合う**
   - 開発用（60 組＋最小対）で、負例が 0 になる高い線を越える
   - 中心の名詞の種類（§4）が同じ
3. どちらでもない → **分からない**（落とす）
4. 1 と 2 が食い違ったら、自動では採らない。開発用のログに残し、人が見て概念表を育てる

## 7. 条件

| 種類 | 形 | 使い方 |
|---|---|---|
| 条件の「なら」・頻度・時 | 〜なら・週に一度・平日の午後・休日に | ① の［A］から落とさない（生成仕様 §7 の 4） |
| 期間 | 十年・五年間・八年間 | ［A］から落とさない。継続の〔期間〕に使う |
| 立場 | 〜として・仕事として・趣味で | ［A］から落とさない |
| 規模 | 小規模な・一式 | ［A］から落とさない |
| **必要の文の条件**（場所・立場） | 現場で・地域で | 相手の句に、はっきり違う条件があれば（遠方の・オンラインで・趣味で など）**分からない**（落とす）。相手の句に条件が無ければ、比べない |
