## 規則（本文）

### 0. 基本の考え方

- 最適化するのは**提示の精度**（偽陽性を最も重く見る）。取りこぼしは相互承認があるので許容するが、併記する
- 作動点は**母集団に依存しない量**で決める。下層と関心の欄は、**固定の背景文集**（65-A §3-1）に対する分位で定める
- 正解の組は 30〜50 対と少ないので、**偽陽性率は背景文集で推定し、取りこぼしは正解の組と C 群で確かめる**

### 1. 下層（この要素に応える相手）

| 項目 | 規則 |
|---|---|
| 作動点 | 必要像の文ごとに、**背景文集との g の 99% 点を上回る**こと（背景からの持ち上がりで判定する C2 の形）。全体で一つの閾値を使う案と比べる場合も、偽陽性の基準は同じ |
| 偽陽性の基準 | 応えない文（A 群・B 群・背景文集）に対する通過率が **1% 以下**（N=100 で要素あたりの偽りが約1件以下） |
| 取りこぼしの下限 | 応える文（C 群・KAORU の最終ラベルで「応える」とされた対）のうち **70% 以上**が通ること |
| 満たせないとき | 偽陽性 1% 以下で取りこぼしの下限を満たせなければ、**下層は開けない**。C5（平均除去）・C6（クロスエンコーダ）をかけた結果で同じ規則を当て、それでも満たせなければ L（LLM の含意判定）の検討に進む |

### 2. 上層（目的を満たす相手）

| 項目 | 規則 |
|---|---|
| 既定 | **現行 0.70 を維持する** |
| 見直す条件 | 架空の母集団で、無関係・話題だけの人が上層を通った例が**1件でもあれば**、上層にも下層と同じ作動点を当てた結果を出し、どちらにするかを KAORU と決める |

### 3. 関心の欄（同じ関心を持つ人）

| 項目 | 規則 |
|---|---|
| 作動点 | 下層と同じ形（背景文集の 99% 点を上回る） |
| 偽陽性の基準 | 関心が一致しない文に対する通過率が **1% 以下** |
| 取りこぼしの下限 | E 群のうち **70% 以上** |
| 比べ方 | 65-A §3-2-6 の (i) 対称／(ii) query×document のうち、上の基準を満たし、取りこぼしが少ないほうを採る |
| 満たせないとき | 関心の欄は開けない |

### 4. 「該当なし」

| 項目 | 規則 |
|---|---|
| (i) | 応える相手がいないプール（無関係な人 100 人）で、要素の「該当なし」を返す割合が **95% 以上** |
| (ii) | 応える相手がいるプールで、「該当なし」を返さない割合が **70% 以上**（取りこぼしの下限と同じ水準） |
| (iii) | プールを 10→100 人にしても (i) が 95% 以上を保つこと |
| 判定 | (i)(ii)(iii) を**すべて**満たした層だけ、「該当なし」を言い切ってよい |

### 5. 報告の形

- 各層について、上の規則に照らして「満たす／満たさない」と、その作動点での偽陽性・取りこぼしを書く
- 規則を満たせない層は、**どの案（C2・C5・C6）でも満たせなかったか**を書く
- KAORU の最終ラベルが付く前の結果は「仮ラベルでの結果」と明記する

## 運用の細目（Code が補った。結果を見る前に決めた）

1. **99% 点の推定と偽陽性の測り方:** 99% 点を決めたのと同じ背景の文で偽陽性を測ると、作りから 1% 前後になる。そこで次のように分ける。
   - 背景文集を固定の規則（文の通し番号の偶奇）で 2 つに分ける
   - 片方（推定用）で 99% 点を決める
   - もう片方（検証用）・A 群・B 群で偽陽性を測る。報告には推定用での値も併記する
2. **関心の欄の背景:** 関心の欄の比べる相手は「〜に関心がある。」の形の文なので、背景文集に**関心の文の節**を設け、その 99% 点を使う。与え像の形の節での値も併記する。
3. **「応えない」文:**
   - 下層では A 群・背景文集（検証用）・役割の必要像に対する B 群。
   - 関心型の必要像（文末が「関心がある人。」）に対する B 群は、話題の関心が一致しうるので「判断できない」として数えない（KAORU の最終ラベルで決める）。
4. **「応える」文:** C 群のうち、その必要像のために書かれた文（target）。KAORU の最終ラベルが付くまでは「仮ラベルでの結果」とする。
5. **「該当なし」の (ii) の「応える相手がいるプール」:** 無関係な人 99 人に、その要素のための C 群の文を持つ人 1 人を加えたプール。
6. **作動点の比べ方:** 規則の形（必要像ごとの 99% 点）を主とし、全体で一つの閾値（0.70 ほか）・C5・C6 は、同じ偽陽性の基準で並べて比べる。

## 運用の細目（追記・計測の結果を計算する前に決めた）

7. **文集の版:** 背景は `scripts/probe_data/background_v1.json`（bg-v1。与え像の形の節 300 文・関心の文の節 150 文）、群は `scripts/probe_data/element_sets_v1.json`（el-v1）。どちらも、この議論を知らない新しい会話に条件だけ渡して書かせた文（条件の全文はファイルに記録）。
8. **分位の求め方:** `numpy.quantile(値, 0.99)`（線形補間）。通過は 99% 点を**上回る**（`>`）とき。
9. **C5（平均除去）:** 推定用の背景の文を、必要像の側（query の接頭辞）と相手の側（passage の接頭辞）でそれぞれ埋め込み、その平均を引いてから L2 正規化しなおす。g は (1 + cos) / 2。作動点は C2 と同じく、必要像ごとの推定用での 99% 点。関心の欄は関心の文の節で同じことをする。
10. **C6（クロスエンコーダ）:** `hotchpotch/japanese-reranker-cross-encoder-small-v1`（MIT・revision 固定）を主に、`BAAI/bge-reranker-v2-m3`（Apache-2.0・revision 固定）を併記する。入力は PII のマスクだけをかけた文（接頭辞なし）の (必要像, 相手の文)。作動点は必要像ごとの推定用での 99% 点。
11. **C4:** 関心型の必要像（文末が「関心がある人。」）を下層の補完に入れない。下層の指標は「全要素」と「役割の要素だけ（C4）」の両方を出す。関心型の必要像は、関心の欄の比べ方（必要像 × 相手の関心）で別に測る。
12. **人の作り方（上層・「該当なし」・一覧の長さ）:**
    - 無関係な人＝背景（与え像の節の検証用）と A 群から、乱数（種 6501）で 3 文を取った人
    - 話題だけの人＝B 群の 2 文の人
    - 応える人＝その要素のために書かれた C 群の文 1 文と、無関係な文 2 文を持つ人
    - 目的を満たす人＝その目的の欠かせない要素それぞれについて C 群の文を 1 文ずつ持つ人
    - 関心の欄の人＝関心の文の節（検証用）から 2 文を取った人。応える人は E 群の一致の相手の文を持つ人
    - プールは 1 条件につき 200 回引き直す
13. **上層の判定:** 現行の `direction()` と同じ形（欠かせない要素すべてに通る対があり、通る対が 1 つ以上）。KAORU の目的は門が立たない（強さ 0.5 未満）ので、門は当てない。欠かせない要素の数 0／1／2 は、目的1 を {}・{1-1}・{1-1, 1-2}、目的2 を {}・{2-1}・{2-1, 2-2} に切り替えて測る。
14. **C 群の文体:** C 群は「〜しました／〜できます」の丁寧体で書かれた。主の結果は書かれたままの文で出し、文末だけを機械的に常体へ直した版（規則はスクリプトに記録）の結果を併記する。
15. **全体で一つの閾値との比較:** 現行 0.70 と、KAORU の必要像 × 推定用の背景をまとめた 99% 点（全体の閾値）を、同じ偽陽性の基準で並べる。
