## 1. 測るもの

| 対象 | 中身 |
|---|---|
| 照合の表 | v0.3.1-dev（2026-11-19 凍結） |
| お手本 | examples_v1（これから作る） |
| ［A］の作り方 | **機械**（offer_quote から、丁寧の形を常体にし、末尾を整える。迷えば型の ①）。指示書77b の §3 |
| LLM（参考だけ） | Nemotron が［A］を書く形。合否には使わない |

- v2 は、表と開発の担当（Claude・Code）が**中身を見ない**。Code は流して数だけを出す
- **合否は「照合の表 v0.3.1-dev ＋ 機械の［A］」で決める**（2026-11-19 改め。v2 を一度も流していないときに決めた。Sakana 九回目・KAORU）
- LLM の［A］（Nemotron）は、同じ v2 で流す**参考の測定**。合否に使わない。記録するのは 3 つ：形の確かめを通った割合・読みやすさの差・言い過ぎや足した語の数
- **LLM を採る条件（いま決める）：**LLM の形も §2 の線 1・2・4 に届き、さらに KAORU が、どちらが LLM か分からない形で並べて読み比べ、LLM の方が読みやすいと判断したとき。それ以外は機械のまま
- LLM の段1（抽出）は使わない。抽出は照合の表が行う

## 2. 合格の線

| # | 物差し | 線 | 合否に使うか |
|---|---|---|---|
| 1 | **出した説明の誤り**（説明できない組に出した・関係や［C］の種類の違い・［A］の言い過ぎ・主語や条件の取り違え） | **1 件以下**（目標 0 件） | 使う（最重要） |
| 2 | **説明できる組のうち、説明が出た割合**（生成の ① か 型の ①） | **50% 以上**（目標 60〜70%） | 使う（足切り） |
| 3 | 出た説明のうち、生成の ① が通った割合（型の ① に落ちなかった割合） | 決めない | 使わない（記録だけ） |
| 4 | 同じ入力で 3 回流して、結果が同じか | **3 回とも同じ** | 使う |

- 2 の分母は、画面に出るはずの組（補完の目的で R4 だけの組を除く。60 組と同じ数え方）
- 線を高くしすぎない（80% などにすると、拾うために言い過ぎを招く）
- **参考に分けて記録する（合否には使わない）：**領域が表の概念の中の組／外の組ごとの、1 と 2 の数。外の組は、表の概念表が知らない領域なので、2 は低くなると見込む（概念表の広がりの限界を知るため）

## 2'. v2 の作り方（2026-11-19 確定）

- 別の会話（プロジェクトの外・新しい会話）に `PoX_v2を作る_別の会話に渡す文_2026-11-19.txt` だけを渡して、60 組と正解を作らせる
- 内訳：説明できる 24（R1 経験 6・継続 2・現職 2・R2 5・R3 所有 3・使える立場 2・R4 4）・説明できない 36。領域は表の概念の中 30・外 30
- KAORU が正解を確かめ、Code に直接渡す。**Claude（表と開発の担当）は v2 の中身を見ない**。Code は数だけを報告する

## 3. 落ちたとき

- v2 を見て、表・プロンプトを直して同じ v2 で測り直すことは**しない**
- 落ちた結果をそのまま記録する。その後に v2 を開いて原因を見るのはよいが、そのときの v2 は「探索」の扱いになる
- 直した版（表 v0.3.2・プロンプトの次の版）は、**新しい v3** で判定する
