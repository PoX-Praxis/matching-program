## 3. 印を外した箇所（§1-1）

| 箇所 | related のときの振る舞い |
|---|---|
| つながる（`/connect`）の目的ごとの表 | 関わっていない相手のカードを返さない（`/v4/match` の `groups[].results` から外す）。カードの印「欠かせない要素をすべて覆う人」も出ない |
| つながるの「いまは、この目的をすべて満たす相手はいません」 | 出さない（`upper_scope` が related のとき） |
| つながるの「あなたを必要としている相手」 | 関わっていない相手を返さない（グループごと出ない） |
| 相手のプロフィールの「あなたの必要から見た、この人」（`/api/connections/preview`） | 下層が閉じている間、関わっていない組には、上層が通っても通らなくても同じ応答（「要素単位の照合は準備中です」）を返す |
| `/v4/match` の応答 | 上の 2 つのほか、`upper_scope` を足した（画面が文言を出し分けるため） |
| 提示の記録 | 出さなかったカードは記録しない（記録は表示したものだけ。記録自体はフラグで閉じたまま） |
| 登録者一覧のラベル（63 PR-E） | 上層の印は無かった（必要像の「欠かせない要素」の印は、その人のプロフィールの性質で、照合の結果ではない）。変えていない |
| 欠かせない要素が無い目的の文言 | 変えていない（つながるの表にも、そのまま出る。本人の目的の性質で、相手についての結果ではないため） |

関わっている組は、もともと `/v4/match` から外れている。外れているのは、接続中・相手から申し出が来ている組と、その目的で申し出中の組。だから、つながるの表に残るのは「別の目的で申し出中の相手」のカードだけになる。

| 案 | 中身 |
