## 順1 — 色に名前を付けて、1 か所にまとめる（§1・§2）

### 1. 禁則抵触の有無／推測で補完した箇所

**禁則抵触: なし**

- 変えたのは色（CSS）だけ
- 文・並び・HTML の構造は変えていない
- 説明の表示の HTML（`src/explanation.py` が出すもの）は変えていない。色はクラスに当てる CSS だけ（テスト 492）。承認した人の表示のハッシュ・pair_digest は変わらない
- サーバーへの保存・クッキー・外部の読み込みは足していない

**推測で補完した箇所（違っていれば直す）**

1. **色の定義の置き場所**
   - 色の名前は `templates/_theme.html` の `:root` に置き、`_base.html` の `<head>` で読み込む
   - 指示は「`_base.html` の `:root`」。`_base.html` を使わないページが 2 つ（`login.html`・`index.html`）あり、そこでも同じ定義を読み込むため、1 つの部品に分けた
   - 定義は 1 か所のまま
   - 順2 の「ちらつきを出さない」ための `<head>` の短いスクリプトも、この部品に置く
2. **色の名前は 29 個**（目安の 24 を 5 つ超えた）。超えた分と理由:
   - 幕（`--overlay`）と影（`--shadow`）: 暗い表示で薄くするため
   - 注意の枠（`--warn-line`）: 注意の文字の色で枠を描くと強すぎるため
   - ボタンを押す前の強調（`--accent-hover`）
   - 説明の 2 つの帯（`--band-rev`・`--band-main`）
   - 「見出し」は本文と、「入力欄の背景」はカードの背景と同じ名前にまとめた
3. **既にあった変数の扱い**
   - ページごとの色の変数（`--ink`・`--ink2`・`--label`・`--rule`・`--navy`・`--pivot`・`--pox-ink` など 19 個）は、役割の名前に寄せて、定義を消した
   - `--ring` は名前をそのまま使う

### 1. 禁則抵触の有無／推測で補完した箇所

**禁則抵触: なし**

- 変えたのは色（CSS）と、§4 の切り替えのボタンだけ。文言・並び・HTML の構造は変えていない
- 説明の表示の HTML は変えていない（`src/` に手を入れていない。テスト 492）。承認した人の表示のハッシュ・pair_digest は変わらない
- サーバーに何も保存しない。クッキーを足さない。ログに出さない
  - 選択は、その人のブラウザの `localStorage`（`pox_theme`）だけ（テスト 497）
  - 実際のブラウザでも、切り替えた後のクッキーは 0 個
- 外部の読み込みは足していない（月と太陽は埋め込みの SVG）
- 3 つ目の選択肢（「端末に合わせる」に戻すボタン）は作っていない
- 画像には色を当てていない

**推測で補完した箇所（違っていれば直す）**

1. **狭い幅の 1 行の置き場所**
   - ☰ の中の「プライバシー」の下、「ログアウト」の上に置いた
   - 印（月／太陽）と「表示を暗くする／明るくする」の文を出す
   - 押してもメニューは閉じない（切り替わったのをその場で見られる）
2. **暗い表示の主なボタン**
   - 地を明るい青（`#8fb8e6`）、文字を暗い紺（`#0c1724`）にした
   - 紺の地に白い文字のままだと、暗い地の上でボタンが沈むため
   - ナビの帯は紺のまま
3. **入力欄の地**
   - ページで地を決めていない入力欄（`textarea`・`select`・文字の `input`）に、`--surface` と `--text` を当てた
   - 暗い表示で、ブラウザの既定の灰色の地にしないため
   - `:where` で強さを 0 にしたので、ページの指定があればそちらが勝つ
4. **影**
   - 影を使うのは ☰ のメニューだけ
   - 暗い表示では薄くし（.18 → .12）、縁の線（`--line-strong`）で見分ける
5. **幕**: ダイアログの後ろの幕は、暗い地の上でも分かるように濃くした（.4 → .6）

### 6. 切り替えの確かめ（実際のブラウザ。Chromium）

- **広い幅**
  - 明るい表示では月が出て、`aria-label` は「表示を暗くする」
  - 押すと暗くなり、太陽に変わる。`aria-label` は「表示を明るくする」になる
- **狭い幅（iPhone 13）**
  - ナビのボタンは出ず、☰ の中の 1 行で切り替わる
  - 1 行の文も「表示を明るくする」に変わる
- **選んだほうが続く**: ページを移っても、開き直しても、選んだほうのまま
- **保存が無いとき**
  - 端末の設定が暗ければ暗い表示、明るければ明るい表示になる
  - 最初の描画の時点で地の色が決まっている（ちらつかない）
- **保存した選択が優先**: 保存した「明るい」は、端末の設定「暗い」より優先される
- **クッキー**: 0 個
