## 順1 — 色に名前を付けて、1 か所にまとめる（§1・§2）

### 1. 禁則抵触の有無／推測で補完した箇所

**禁則抵触: なし**

- 変えたのは色（CSS）だけ
- 文・並び・HTML の構造は変えていない
- 説明の表示の HTML（`src/explanation.py` が出すもの）は変えていない。色はクラスに当てる CSS だけ（テスト 492）。承認した人の表示のハッシュ・pair_digest は変わらない
- サーバーへの保存・クッキー・外部の読み込みは足していない

**推測で補完した箇所（違っていれば直す）**

1. **色の定義の置き場所**
   - 色の名前は `templates/_theme.html` の `:root` に置き、`_base.html` の `<head>` で読み込む
   - 指示は「`_base.html` の `:root`」。`_base.html` を使わないページが 2 つ（`login.html`・`index.html`）あり、そこでも同じ定義を読み込むため、1 つの部品に分けた
   - 定義は 1 か所のまま
   - 順2 の「ちらつきを出さない」ための `<head>` の短いスクリプトも、この部品に置く
2. **色の名前は 29 個**（目安の 24 を 5 つ超えた）。超えた分と理由:
   - 幕（`--overlay`）と影（`--shadow`）: 暗い表示で薄くするため
   - 注意の枠（`--warn-line`）: 注意の文字の色で枠を描くと強すぎるため
   - ボタンを押す前の強調（`--accent-hover`）
   - 説明の 2 つの帯（`--band-rev`・`--band-main`）
   - 「見出し」は本文と、「入力欄の背景」はカードの背景と同じ名前にまとめた
3. **既にあった変数の扱い**
   - ページごとの色の変数（`--ink`・`--ink2`・`--label`・`--rule`・`--navy`・`--pivot`・`--pox-ink` など 19 個）は、役割の名前に寄せて、定義を消した
   - `--ring` は名前をそのまま使う

### 3. 寄せたことで、明るい表示の見た目が変わったところ

約 130 種類の色を 29 の名前に寄せた。主なページを、置き換えの前（main）と後で同じ合成データで撮って比べた（幅 1000）。変わった画素の割合:

| ページ | 変わった画素 |
|---|---|
| つながる | 0.01% |
| 相手のプロフィール（説明） | 0.09% |
| 受信箱の一覧 | 0.01% |
| 詳細（承認） | 0.07% |
| マイページ | 0.17% |
| 言語化する | 0.05% |
| コミュニティ | 0.14% |
| ログイン | 0.06% |
| プライバシーポリシー | 0.00% |
| PoX とは | 0.01% |

目で見て分かる違い:

- **薄い文字**（`#888`・`#999`・`#aaa` など）
  - `#6e7279` に寄せた。少し濃くなった
  - 地との比を 4.5 以上にするため（いまの `#888` は白地で 3.54）
- **ナビの「☰」の枠**: 暗い紺（`#4a6a8c`）から、ナビのリンクの色（`#ccddee`）になった。少し明るい
- **明るい青の文字**（`#1a56bb`。照合の根拠の「意志」の印・プロフィールの古い段階の印）: リンクの紺に寄せた
- **紫の印**（軌跡の「コミュニティに参加」）: 印の紺（`--mark-bg`・`--mark-text`）に寄せた
- **明るい緑**（`#1a8a1a`。「保存しました」などの成功の文字）: 成功の緑（`#1a6a3a`）に寄せた。少し暗い
- **薄い赤の枠**（言語化するの誤りの欄・トークの「危ない」ボタン）: 誤りの赤（`#cc0000`）の枠になった。はっきりした
- **やり取りの「自分の発言」の線**: 淡い緑から成功の緑（濃い）になった
- **押せないボタンの灰色の地**: 少し明るい灰色（`#cfd3d9`）になった
- **見送りのボタンの茶色**（`#8a4a00`）: 注意の茶（`#856404`）に寄せた
