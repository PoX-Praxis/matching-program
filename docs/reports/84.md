# 報告 84 — explain-v07 を本番の既定にする（順1。2026-11-27）

順1 は費用 0。モデルは動かしていない。本番の DB と Render の環境変数は変えていない。表示のフラグは切ったまま。

## 1. 既定の版
- `POX_EXPLAIN_VERSION` が無いときの版を explain-v07 にした
  - 鍵は `explain-v07:331fa7d5…` で、指示書83 のときと同じ
  - explain-v06 と p81 は残してあり、`POX_EXPLAIN_VERSION` で選べる
- 本番の DB には、生成したカードを保存していない（追補3 で入れなかった。11-25・11-26 の回も本番に保存していない）

## 2. 生成は許可リストの組だけ
- 許可リストは `POX_EXPLANATION_ALLOWLIST`。表示のフラグが使うものと同じ
- 確かめる場所
  - 予定に積むとき：登録・編集・同意のきっかけと、運営の口の enqueue
  - まとめて作るとき：予定の行が許可リストに無ければ作らない（skipped・not_allowlisted）。ジョブも起こさない
  - 組ごとに、推論先へ送る前にもう一度確かめる
- 二人のどちらかに入力が無い組でも、ジョブを起こさない（skipped・inputs）

## 3. 費用の歯止め
| 歯止め | 値 | 当たったとき |
|---|---|---|
| ジョブの許可 | `POX_EXPLAIN_JOBS_PERMITTED=1` のときだけ | 起動しない（jobs_not_permitted） |
| 1 日 | 日本の暦で 1 回まで（コードに固定。決定 2026-11-24） | 起動しない（daily_limit） |
| 1 か月 | `POX_EXPLAIN_JOBS_PER_MONTH` 回まで。無い・読めないときは 0 | 起動しない（monthly_limit・monthly_limit_unset） |
| 割り当て待ち | 2 時間 | ジョブを取り消して止める（ほかの GPU に替えない） |
| 起動（動き出してから口が返事をするまで） | 25 分 | ジョブを取り消して止める |
| 動き出してから | 55 分（#232）。ジョブの中で vLLM を止める | 本番の側が止まっていても効く |
| Jobs の上限 | 3 時間（割り当て待ち 2 時間と動く 55 分が入る長さ） | — |

- 起動の数え方
  - ジョブを起こす前に、起動の行（表 explanation_job_launches）を書く。途中で止まっても 1 回と数える
  - 日と月は日本の暦で区切る
- 上限に当たったときは起動しない。組は予定に残し、まとめて作る回の記録に理由を書く
- 運営の口 status に、今日と今月の起動の数・上限・いま起動できるかを出す（数だけ）
- 費用の上限の見積もり
  - 1 回：55 分 × $5／時 ＝ 約 $4.58
  - 1 か月：月の回数 × $4.58 まで

## 4. 起動のきっかけ（いまの作り）
| きっかけ | 動き |
|---|---|
| 登録・編集（v4・v5）・同意 | 予定に積むだけ。hf_jobs のときは、すぐには起動しない |
| 裏の見回り | 10 分ごとに見る。予定があり、前の回から 24 時間（`POX_EXPLAIN_INTERVAL_HOURS`）過ぎていれば作る |
| 運営の口 `POST /ops/explanations/drain`（drain の鍵） | すぐ作る。`{"enqueue": true}` で、許可リストの組を先に積む |

- どのきっかけも、§3 の歯止めを通る
- 裏の見回りは、Render の無料の入れ物が起きているあいだだけ動く（要求が 15 分無いと入れ物は止まる）。そのため、作る時刻は決まらない。止まっていた分は、次に起きた後に作る
- 定時にするときの案（この PR では入れていない。KAORU が決める）
  - 時刻：日本の朝 6:10（UTC 21:10）。二人が朝に見る前に作り終えるため
  - 作り：無料の入れ物は寝ているので、外から drain の口を呼ぶ（例：GitHub Actions の schedule `10 21 * * *`。drain の鍵は GitHub の secret に入れる）。裏の見回りは、その時刻の前後だけにするか止める

## 5. 作り直し（テスト 600）
- どちらかが登録し直すと、組は 1 行だけ積まれる
  - 二人とも・何度登録し直しても、作るのは 1 回
  - 作っている途中に登録し直した場合は、終わった後に 1 回だけ作り直す
- 見つけて直したこと
  - **v4 の人の登録・編集では、組を積んでいなかった。** 前は、v5 の確定と同意のときだけ積んでいた
  - **v5 の確定は、ベクトルの作成に失敗すると組を積まずに終わっていた。** 説明の入力はベクトルを使わないので、失敗しても積むようにした
- 足したこと：いまの入力・いまの版のカードが二つの向きともあれば、積まない（入力が変わらない登録でジョブの費用をかけない）

## 6. Render の環境変数（名前だけ。値は書かない）
**順3 のために入れるもの**
| 名前 | 意味 | 入れなかったとき |
|---|---|---|
| `POX_EXPLAIN_BACKEND` | 推論先。`hf_jobs` にする | 作らない（積まない・起動しない。drain の口は backend off を返す） |
| `POX_HF_TOKEN` | HF のトークン（Jobs を起こせるもの。HF の前払いの残高が要る） | `POX_EXPLAIN_BACKEND=hf_jobs` のとき、**本番が起動しない**（起動の確かめで止まる） |
| `POX_EXPLAIN_JOBS_PERMITTED` | ジョブの許可。`1` にする | 起動しない（予定に残す） |
| `POX_EXPLAIN_JOBS_PER_MONTH` | 1 か月の起動の上限（回）。KAORU が決める | 0 として扱い、起動しない |

**もう入っているもの（そのまま）**
| 名前 | 意味 | 入れなかったとき |
|---|---|---|
| `POX_EXPLANATION_ALLOWLIST` | 許可リスト（KAORU×PA）。表示のフラグと同じ | 積まない・作らない |
| `POX_EXPLAIN_DRAIN_TOKEN` | 運営の口の鍵（32 字以上） | 運営の口（drain・status・export・input・replay）が 404 |

**任意**
| 名前 | 意味 | 入れなかったとき |
|---|---|---|
| `POX_HF_NAMESPACE` | ジョブを起こす HF の名前 | トークンの持ち主の名前を使う |
| `POX_EXPLAIN_INTERVAL_HOURS` | 裏の見回りの間隔（時間） | 24 |

**入れないもの**

- `EXPLAIN_CELLS`・`EXPLAIN_BOUND_FOR_NO_PURPOSE`・`EXPLAIN_STRIP_LABEL_WORDS`：版の鍵が変わる
- `POX_EXPLAIN_ENDPOINT`・`POX_EXPLAIN_ENDPOINT_KEY`・`POX_EXPLAIN_GPU`：PC（local_http）用
- `POX_EXPLAIN_N_GPU_LAYERS`・`POX_EXPLAIN_N_CPU_MOE`：p81 の PC 用
- `RENDER_EXTERNAL_URL`・`RENDER_GIT_COMMIT` は Render が入れる（まとめて作るあいだ入れ物を起こしておく・版の記録）
