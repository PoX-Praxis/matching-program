# 報告（docs/reports/）

指示書ごとの報告を 1 ファイルずつ置く。決まりは `docs/OPERATIONS.md` §2、テンプレートは `_template.md`。

## 置き方

- **ファイル名:** 指示書と同じ `<番号>.md`（例: `66.md`・`repo-operations.md`）
  - 1 つの指示書で報告を何回か出したときは、枝番を付ける（例: `66-PR-66B.md`・`66-PR-66C.md`）
- **入れる時:** その指示書の最後の PR の、最後のコミット。同じコミットで `docs/status.md` を更新する
- **計測の報告:** 集計・判定・材料の識別子は `docs/measure/` に置き、報告からはその文書を指す

## 過去の報告は、後から入れる

指示書06〜66 の報告は、リポジトリの外（作業したセッションの作業領域・チャット）にある。いまはここに無い。

- 入れるときは、まとまりごとに 1 コミットにする
- 各ファイルの冒頭に、次の 3 つを書く
  - **後から入れた**ことと、入れた日
  - **元の日付**
  - **対応する PR の番号**
- 報告の中の「次にすること」が、いまの状態と食い違っていても、本文は直さない。冒頭に「時点の記録（YYYY-MM）。いまの正は `docs/status.md`」と書き足す

## 入れるときの除外の決まり

`docs/OPERATIONS.md` §5 に当たるものは伏せる。報告で特に気をつけるのは次のもの。

| 伏せるもの | 例 | 置き換え方 |
|---|---|---|
| 個人の文 | KAORU・PA の文、抜き取りの票に載せた文、上層を通った人の文の一覧 | 識別子と件数だけにする（例: 「一覧 N 文。本文は `local/66/c/`」） |
| 生テキスト・根拠の本文・`evidence_span` | 監査の応答の引用 | 「（伏せた）」 |
| 本人以外の数値 | PA の gate・PA との照合の g | 「（PA の数値・伏せた）」 |
| 計測の個別の数値 | 対ごと・人ごと・文ごとのスコア | 集計（曲線・AUC・判定）は残してよい。個別の値は `local/` を指す |
| 秘密 | トークン・メールアドレス | 「（秘密・伏せた）」 |

- 伏せたら、冒頭に「伏せた部分」を書く
- 判断に迷うものは入れずに、報告の「判断が必要な点」に挙げる
