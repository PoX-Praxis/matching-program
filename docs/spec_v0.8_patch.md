## A. 事実の訂正（v0.7 の記述が実態と食い違っていた箇所）

### A-1. Postgres 移行は完了済み【§3-2 の訂正】
- 2026-06-19（コミット `0313dd2`）で PostgreSQL + pgvector に移行済み。
- 実態は「切替式」：`DATABASE_URL` があれば Postgres（本番/Render）、なければ SQLite（ローカル）。全モジュールは `get_connection()` 抽象を通す。
- `GET /v4/seekers/<id>/status` も本番で応答する。

### A-2. embedding モデルは Nomic に確定【§1-7・§0・§5 の訂正】
- Nomic（nomic-embed-text-v2-moe / 768次元 / Apache 2.0）に確定。本番 `POX_EMBED_MODEL_TAG=nomic-emb-v2`。
- `src/embedding_config.py` の `MODEL_TAG` 既定値は `qwen3-embedding-0.6b-d1024` のままだが環境変数で上書き。**既定値は変更しない**（変更すると次元 1024→768 が食い違い全ベクトル再索引が必要）。

### A-3. 「embedding は母数まで待機・LLM 代行継続」は転換済み
- Postgres 移行と Nomic 確定を経て **v4 照合系が本番の主経路**。「つながる」も v4 照合一本。

## B. 公開範囲の確定

### B-1. 情報ごとの公開範囲

| 情報 | 他人ビュー | 本人ビュー | 保存 |
|---|---|---|---|
| seeker 原文（意志・現状・生テキスト・素材） | 非公開 | 表示 | 保存 |
| `necessity_text`（必要像本文） | **公開** | 表示 | 保存 |
| `evidence_span`（根拠引用＝原文の一部） | **非公開** | 表示 | 保存 |
| 数値（gate_s/gate_u/gamma/p/α/β） | 非公開 | 非公開（当面） | 保存 |
| generator_name | 非公開（当面） | 非公開 | 保存 |
| 接続の事実（誰と誰が・成立/終了。**理由は記録しない**） | **公開（第三者可）** | 表示 | 保存 |
| 接続時点に書いた脆弱な内容 | **本人が第三者に非公開にできる**（相手には表示） | 表示 | 保存 |
| 承認待ち（片側承認） | 当事者のみ | 表示 | 保存 |

- 必要像の公開は**「今後の登録から」**。既存登録者は再構造化で移行。遡及しない。
- evidence_span を他人に見せない理由：原文の一部であり、seeker 原文遮断（指示書09）と衝突するため。本人には自己認識のため見せる。
- 数値を公開しない理由：各自の AI 申告値で尺度が揃わず（比較不能）、公開すると格付け化・再生成の誘発を招く。

### B-2. 接続は「事実のみ」公開（理由は残さない・脆弱な中身は伏せられる）
**設計思想:** 軌跡・接続の記録は「今の利用者同士の意味」のためにある。後の人のためのアーカイブは結果であって目的ではない。衝突時は常に「今の正直な接続と当事者の尊厳」を優先。
- 接続の**事実**（誰と誰が・いつ成立し・いつ終わったか）は、成立・終了を問わず**第三者にも公開・消せない**。
- **理由は記録しない**（なぜ接続/終了したか）。理由は編集・争い・因果主張を生む。
- **脆弱な時点の中身**は**本人が第三者に非公開にできる**（相手には見える）。結末そのものは伏せられない。

## C. 編集・変化・軌跡の確定

### C-1. 変更経路と保存トリガー

| 経路 | ベクトル | 必要像 | スナップショット |
|---|---|---|---|
| 再構造化（新JSON登録） | 再計算 | 同時に再生成 | **1点保存（チェックポイント）** |
| プロフィール編集（意志・現状） | 再計算（指示書08） | 古くなる（`needs_regeneration`） | 保存しない |
| 自由記述（view_overrides） | 不変 | 不変 | 保存しない |

### C-2. スナップショットの永続と削除
- 全項目保存・不変。接続に参照された点は本人の一存で消せない。参照なし点のみ削除可。
- 成立時、両者のその時点の最新スナップショットを vessel に結びつける（不変）。

### C-3. 軌跡の表示層
3層（timeline / diff / narrative）のうち **MVP は timeline のみ**。diff・narrative は次段。narrative は自己理解を左右するリスクがあり最後。
