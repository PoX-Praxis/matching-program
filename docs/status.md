## 本体

- Flask 1 本（`app.py`）と `src/`。本番は Render（`pox-web`）と Postgres（pgvector）
- **v5 の流れ:**
  1. **構造化:** 利用者が自分の AI に `docs/prompts/`（rev4）を渡して JSON を作る。`/register` で下書きにし、確定する。確定のときは台帳に先に書く
  2. **nomic の非対称検索:** PII をマスクしてから埋め込む（`nomic-emb-v2`・768 次元）。必要像の文は query、与え像・現状は passage にする
  3. **上層の判定:** 目的の必須がすべて満たされたときだけ成立する（連言）。共鳴の門もある。作動点は暫定
  4. **引用の根拠:** 文の対を引用して示す。数値は画面と公開 API に出さない。並びは中立
- 照合の後は、申し出 → 承認 → DM。事実は追記専用の台帳に書き、毎日アンカーを刻む
