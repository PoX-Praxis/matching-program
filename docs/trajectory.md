# 軌跡（版ごとのツリー・指示書50 v3）

更新: 2026-09-28 ／ 実装: `src/trajectory.py`・`GET /api/timeline/<user_id>`・`templates/_trajectory.html`・`/trajectory/<user_id>`

## 版と枝

- **版** = `user_snapshots` の 1 点。版番号は台帳 `profile.structured` の `n`（同じ `content_hash`）。台帳に無い古い点はスナップショットの序数。
  - 版を作るのは**意志・現状・表示用項目（背景・一行紹介・意志_どこへ・意志_なぜ・経験・要約文）の本文の変化**だけ（`subject_ledger.profile_content_hash` と同じ範囲で churn 判定）。**表示名・読み方などの装飾と `view_overrides`（本人より）は版を作らない**。
  - 必要像の本文は `content_hash` に含まれない。必要像は意志・現状から生成されるため、本文が変わらず必要像だけが変わる経路は現状ない。
  - 出所: 最初の版は「登録」、以後は「再構造化」。
  - 台帳に版があってスナップショットが無い場合は、番号の**欠番**として現れる（詰めて表示しない）。
- **枝** = その版から生まれた関係。**既存の面で既に公開されている事実だけ**（軌跡が可視性を広げない）。

| 枝 | 出所 | 既存の公開面 |
|---|---|---|
| 接続 | 台帳 `connection.established`（新設なし）。相手の版は成立時に結合したスナップショット | 接続の事実は第三者に公開（ポリシー §3-4） |
| 接続の終了 | 同上（`terminal_state`・`closed_at`） | 同上（成立・終了とも公開） |
| 宣言 | 提議トークの立ち上げ（`talks.kind=proposal`・`created_by`）。個人に紐づけて引ける | 提議トークは閲覧公開（指示書43 §1-6） |
| 参加 | 台帳 `intent.participant.joined`（承認された参加のみ） | プロジェクト参加は公開（指示書47） |
| 加入 | 台帳 `member.joined`（成立した加入のみ） | コミュニティのメンバー一覧は公開 |
| 完了 | 台帳 `intent.completed`（その時点で本人が参加者） | 完了プロジェクトは一覧・詳細で公開 |

見送り・却下・加入の申請中は、構造上どの出所にも現れないので載らない。

## 可視性

| 項目 | 本人 | 接続の相手 | 第三者（未ログイン含む） |
|---|---|---|---|
| 意志・現状・必要像・表示用項目 | ○ | ○ | ○（伏せた時点は ×） |
| 根拠（`evidence_span`）・内部数値・raw（生テキスト等） | ○ | × | × |
| 事実（日付・種別・回数・枝） | ○ | ○ | ○ |

- 伏せは既存の `vulnerable_hidden`（第三者にだけ伏せる。接続の相手には見える）を軌跡にも適用する。**軌跡用の別設定は無い**。既定はオフ。
- 伏せの変更は `snapshot_visibility_log` に追記型で残す（表示しない）。
- 第三者への必要像の本文は、既存の公開閾値（`POX_NECESSITY_PUBLIC_SINCE`・指示書11/37）より後に作られた時点だけ。
- 現在の版は本文を出さず「上の『いまの姿』に表示中」。
- `/api/timeline` と `/trajectory/<id>` は `X-Robots-Tag: noindex, nofollow`。過去版は `#vN` のアンカーで指す（単独ページは無い）。
- 表示: 色は種別の識別のみ（ラベル併記）。時間は等間隔にしない（版で刻む）。因果の矢印・「なぜ」の欄は作らない。注記「並び順は時間順であり、因果ではありません。」を常に出す。
- 宣言の枝で、その提議トークに `redaction.recorded` があれば「一部が伏せられています」と出す。プロフィールの時点（版）の本文を削除する経路は現状ない。
