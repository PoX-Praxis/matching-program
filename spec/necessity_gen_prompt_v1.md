## 出力スキーマ（②が返す純粋 JSON）

```json
{
  "necessity_text": "候補者の現状記述と同じ意味空間に乗る自然文の必要像",
  "gate_s": 0.0,          // 相手に意志・姿勢まで求める強さ 0..1
  "gate_u": 0.0,          // 不確実性 0..1
  "p_sharpness": 0.0,     // 結合鋭さ（連言が強いほど負、選言/既定は0寄り）
  "alpha": 1.0,           // 共鳴（同じ志）重み ≥0
  "beta": 1.0,            // 補完（不足を埋める）重み ≥0
  "evidence_span": "意志要求と判断した根拠の引用",
  "generator": "ChatGPT-5"  // ★構造化に使ったAIの名前（自由記述）。不明/未申告は省略可
}
```

二軸（意志・現状）は本文入力として与えられる（下記 USER プロンプト）。②はそれを消費して上記を出す。
`generator` は**利用者が構造化に使ったAI名**（例 "ChatGPT-5", "Claude", "Gemini"）。統制語彙ではなく自由記述。
受け取り側は `derived_necessity.generator_name` に保存する（欠損時 `"user-supplied(unknown)"`）。
※ サーバー生成フォールバックでは `generator` は出さない（経路識別は `generator_model_tag` 側が持つ）。

## gate_s / gate_u の申告基準（判断A(1)・厳密定義）

数値の意味を全AI・全利用者で揃えるための基準。0.0/0.3/0.6/0.9 を目安に補間する。

### gate_s（相手にも「意志・姿勢」まで求める強さ）
- **0.0**: 能力・スキルさえ噛み合えばよい。相手の思想・志は問わない（例: 「実装を代行できる人」）。
- **0.3**: 基本は能力重視だが、最低限の誠実さ・当事者性はほしい。
- **0.6**: 能力に加え、同じ課題への共感・向き合う姿勢を明確に求める。
- **0.9**: 「同じ世界を作りたい」という意志の一致が必須。能力より志を優先（例: 共同創業の同志）。

### gate_u（不確実性：素材の薄さ・迷い）
- **0.0**: 意志も現状も素材が厚く、必要像を高い確信で言い切れる。
- **0.3**: おおむね言えるが一部推測が混じる。
- **0.6**: 素材が薄い／「未取得」が多い／本人も迷っており、必要像が揺れる。
- **0.9**: ほぼ手掛かりが無く、必要像は仮説に近い（取りこぼし回避のため補完を広めに）。

> 禁止（D-2）: `gate_s` に固定フロアを足さない（幻の意志要求を捏造しない）。バイアスは `gate_u` に載せる。
