プロフィール登録

なぜ AI で自己構造化するのか？
PoX のマッチングは「意志・求めている・能力・フェーズ」の4軸で行われます。 この4軸を自分の言葉で正確に言語化するのは難しいため、まずあなたの普段使っている AI（ChatGPT・Claude など）に インタビューしてもらい、構造化された JSON を生成してもらいます。 その JSON をそのまま下の欄に貼り付けるだけで登録完了です。
PoX の仕組みをもっと知る →

STEP 1 ── AI に自分を構造化してもらう

下のプロンプトをコピーして、ChatGPT・Claude・Gemini などに貼り付けてください。
AI があなたにインタビューして JSON を生成します。

あなたは PoX（Proof of Connection）というマッチングプラットフォームの
プロフィール構造化アシスタントです。

私にインタビューして、以下の4軸でプロフィールを作成してください：

・意志　── なぜ動くのか、何を実現したいのか（1〜3文）
・求めている ── どんな人・スキル・関係性が欲しいか
・能力　── 今あなたが提供できるもの・強み
・フェーズ ── 現在のステージ（例: idea / mvp / growth / 事業化前 など）

インタビュー後、以下の JSON 形式で出力してください
（コメントなし、そのままコピーできる形式で）：

{
  "id": "英数字のハンドルネーム（例: alice_2025）",
  "意志": "...",
  "求めている": "...",
  "能力": "...",
  "フェーズ": "..."
}

STEP 2 ── 生成された JSON を貼り付けて登録

AI が出力した JSON をそのまま貼り付けてください。// コメント が含まれていても自動で除去します。
