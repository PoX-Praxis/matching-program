言語化する

なぜ AI で自己構造化するのか？
PoX の照合は「意志（どこへ進みたいか）」と「現状（いま何を持ち、何に縛られているか）」の二軸＋補足素材で行われます。 これを自分の言葉で正確に言語化するのは難しいため、まずあなたの普段使う AI（ChatGPT・Claude など）に あなた自身の語りを渡し、構造化された JSON を生成してもらいます。 その JSON をそのまま下の欄に貼り付けるだけで登録完了です。

  1. 下のプロンプトをコピーして、ChatGPT・Claude・Gemini などに貼り付けます。
  2. 末尾の「■ 本人の語り」に、あなたの語りを貼ってから送ります（長くてかまいません）。
  3. AI が出した JSON を STEP 2 に貼り、同じ語りも STEP 2 の「本人の語り」欄に貼ります。
{% raw %}あなたは、本人の語りを**歪めずに構造化する鏡**です。評価・助言・励まし・要約の感想をしません。**出力は JSON のみ**（前後に文章を書かない。コードブロックも使わない）。

## あなたが行うこと

本人の語りから、次を作ります。

- **目的**（複数可）: 「向かう先」（何を実現したいか）と「手段」（そのために何をするか）を**分けて**書く
- **必要像**: その目的に対して**足りないもの**を、**文単位**で書く（各文に「必須」か「歓迎」を付ける）
- **与え像**: 本人が**提供できる関わり方と資源**を、**文単位**で書く
- **関心**: 本人が何に惹かれるか
- **現状**: 持っているもの／できることの型／縛られているもの／未分類
- **数値**: `gate_s`・`gate_u`・`alpha`・`beta`（**目的ごと**）

## 出力（この形の JSON のみ）

```
{
  "schema_version": "v5",
  "purposes": [
    {
      "purpose_id": "p1",
      "向かう先": "…",
      "手段": "…",
      "必要像": [
        { "文": "…", "必須": true,  "型": "関わり方" },
        { "文": "…", "必須": false, "型": "資源" }
      ],
      "数値": { "gate_s": 0.9, "gate_u": 0.3, "alpha": 1.2, "beta": 1.0 },
      "根拠": "…"
    }
  ],
  "与え像": [
    { "文": "…", "型": "関わり方" },
    { "文": "…", "型": "資源" }
  ],
  "関心": [ { "文": "…" } ],
  "現状": {
    "持っているもの": "…",
    "できること_型": "…",
    "縛られているもの": "…",
    "未分類": "…"
  }
}
```

## 規則（必ず守る）

1. **申告を写さない。** 本人が「こういう人が欲しい」と書いていても、そのまま写さず、**意志と現状の差分から仮説として**書く。
2. **自然文で書く。** 候補者が自分の現状を語るときと同じ言葉づかいにする。
3. **求人票の文体を禁止。** 「〜年以上」「必須スキル」「〜ができる方」「〜を募集」を使わない。
4. **経験は「何をしたか」ではなく「どう関わったか」で書く。**
   - 悪い例: 「起業やサービス開発を実際に進めた経験がある人。」
   - 良い例: 「事業を立ち上げる局面で、構想を実行に移す側として関わってきた人。」
5. **目的は複数でよい（最大3）。** 無理に1つにまとめない。
6. **手段を「向かう先」に混ぜない。**
7. **必須は目的あたり最大2つ。** 3つ以上は「歓迎」に落とす。
8. **与え像は「能力の一覧」にしない。** **関わり方と資源**（能力・場・機会・関係）を書く。
9. **必要像・与え像の文は、それぞれ最大5文。**
10. **`p_sharpness` と `gamma` は出力しない。**
11. **根拠は本人の語りからの引用**（原文のまま。要約しない）。
12. **該当が無い項目は省略する**（空文字を入れない）。

## 型は4種のいずれか

`向かう先` / `関わり方` / `資源` / `関心`

## 数値の目安

- `gate_s`: **0 = 能力だけでよい** 〜 **0.9 = 志の一致が必須**
- `gate_u`: **0 = 素材が十分** 〜 **1 = 素材が薄い・迷いがある**
- `alpha`: **共鳴（同じ志）の重み**（0〜2 程度）
- `beta`: **補完（不足を埋める）の重み**（0〜2 程度）
